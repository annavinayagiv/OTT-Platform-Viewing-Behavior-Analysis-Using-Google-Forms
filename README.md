# OTT Platform Viewing Behavior Analysis

## Project Overview

This project focuses on analysing user viewing habits and preferences across OTT (Over-The-Top) streaming platforms using survey data collected through Google Forms.

The objective is to understand user preferences, viewing patterns, and OTT platform usage through data analysis and interactive visualizations in Power BI.

## Objectives

- Understand users' OTT platform preferences.
- Analyse viewing habits and streaming behaviour.
- Identify patterns in user preferences.
- Explore trends in OTT platform usage.
- Present insights through interactive Power BI dashboards.

## Data Collection

- **Data Collection Method:** Google Forms
- **Data Source:** Survey responses collected from OTT users.
- **Dataset Format:** CSV / Excel

*Personal information, including email addresses, has been excluded from the publicly shared dataset.*

## Tools Used

- Google Forms – Data collection
- Microsoft Excel – Dataset handling
- Microsoft Power BI – Data analysis and visualization

## Project Workflow

1. Designed a questionnaire using Google Forms.
2. Collected survey responses from users.
3. Prepared and organized the collected data.
4. Analysed the data using Power BI.
5. Created visualizations to understand OTT viewing behaviour.
6. Presented the findings through a Power BI dashboard.

## Key Areas of Analysis

- OTT platform preferences
- User viewing habits
- Streaming behaviour
- Content preferences
- Patterns in platform usage

## Dashboard and Visualizations

The project includes Power BI visualizations to present survey findings and highlight patterns in OTT platform usage.

## Conclusion

This project provides insights into OTT platform usage and user viewing preferences through survey-based data analysis.

Power BI was used to transform the collected responses into meaningful visualizations, making it easier to understand viewing patterns and user behaviour.
